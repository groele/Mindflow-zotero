# MindFlow for Zotero V10 — 10.0.0

日期：2026-09-28。标签：`v10.0.0`。兼容 Zotero `10.0.x`；真实桌面验证使用 Zotero `10.0.3`、PowerShell `7.6.6`。

## 修复范围

V10 汇集 [首轮 42 项审查与改进](审查与修复清单.md) 和 [全流程复审的 28 项补充问题](全流程逻辑复审-5.0.2.md)，逐项清单保留发现依据、影响、修复和验证路径。

核心变化包括：文献库/条目/附件/文档身份严格区分，选中目标与实际打开内容对应，同内部 ID 的不同来源隔离，实际标签上下文同步，多窗口版本冲突保护，保存/删除/归档统一排队，持久删除标记，关闭与退出捕获未保存文字，真实会话和撤销关闭恢复，损坏备份恢复，快照并发与归属校验，以及工具栏布局修复。

品牌图标旁文字已移除，保留图标工具提示与可访问名称。插件清单、包版本、锁文件、关于页、欢迎页、导出备份版本及两份更新元数据统一为 `10.0.0`；界面和备份版本从包版本读取。

发布复现检查还发现 Tailwind 自动扫描范围受构建目录影响。现已固定为前端源码目录；按 lockfile 独立安装依赖后构建，JavaScript 和 CSS 均与交付产物逐字节一致。

最终包的真实重启验收还复现了解除关联的冲突副本被误送入附件导入逻辑，重启后生成新 ID。现已将撤销关闭与会话恢复标记为明确的工作区目标，只读取对应的有效持久记录；不导入旧负载、不生成副本。保存的标签恢复到标签模式，避免当前独立窗口偏好改变恢复位置。新增回归覆盖无附件文档、落后负载、身份不符和已删除目标；真实重启同时核对没有新增工作区克隆。修复前的失败证据保留在 `v10-pre-release-restart-failure.json`。

## 安装与边界

在 Zotero“工具 → 插件 → 从文件安装插件”选择 XPI，完成安装后重启。沿用原插件 ID，可覆盖旧版；升级前建议备份。

测试使用隔离的配置与数据目录。尚未实际验收群组库权限、云端附件同步、真实 AI/WebDAV 账户、长期压力和断电恢复。全工作区恢复为逐文档提交。历史错误关联无法凭标题自动推断原归属，仍需人工核对。
