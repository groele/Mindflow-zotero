# AI 论文研究导图

这项功能面向 Zotero 10 中的**单篇常规文献**。它把已有的题录、摘要、文献笔记、PDF 批注和可提取的 PDF 文字整理成一张新的可编辑导图，帮助读者先看清论文的研究动机与论证路径，再回到原文核对。

## 配置与启动

1. 打开 Zotero 的 **编辑 → 设置 → MindFlow → AI 论文研究导图**。
2. 填写兼容 Chat Completions 请求格式的完整接口地址、模型名称与 API 密钥。公网地址必须使用 HTTPS；只有本机 `localhost`、`127.0.0.1` 或 `::1` 允许 HTTP。本机服务可不填密钥。
3. 在文献列表只选中一篇论文，右键选择 **AI 解析论文并生成研究导图**。工作台 Zotero 菜单也有相同入口。模型没有配置时，工作台会给出提示并打开 MindFlow 设置。
4. 等待工作台显示本地保存和 Zotero 归档结果。归档失败时，新导图仍可能已保存于本机工作区；请按提示检查所属文献库的附件写入权限。

## 导图结构

主干依次是：研究背景、已有问题与知识缺口、研究目标、研究体系、方法设计、关键结果与证据、解决的问题、创新意义、局限和后续验证。每个主干最多显示五条分析。资料不足的主干明确显示“待阅读原文补充”。

节点的标记代表证据边界：

- **原文支持**：模型给出的短引文在送出的摘要、PDF 文字或 PDF 批注划线原文中找到了匹配。读者笔记与批注评论不会单独被当成论文原文证据。节点备注保留引文与来源；这是文本匹配，不代表结论已经过独立科学验证。
- **推断/待核验**：没有可匹配的直接引文，或模型把内容标为分析推断。应用场景、机制和意义需要回到原文确认。
- **待解决**：论文尚未回答的问题或建议的后续验证方向，不应写成作者已经证明的结果。

批注节点若有 Zotero 定位链接，可直接返回原标注；PDF 文字节点可打开关联 PDF。PDF 提取文字没有可靠的逐句页码定位，因此不自动生成页码引用。

## 资料范围与隐私

- 只有用户点击生成入口时才发出 AI 请求。发送内容包括题录、摘要、最多 8 条笔记、50 条批注及本机 PDF 最多前 50 页的可提取文字；特别长的 PDF 文字会保留开头与结尾节选并标记截断。
- 本功能不执行 OCR，不会自动下载云端 PDF。扫描版、加密版或未下载的 PDF 可能仅能依据摘要、笔记和批注分析。根节点备注会列出实际资料范围。
- 论文资料被发送到用户配置的模型服务，需自行确认该服务的隐私、授权、费用与数据保留规则。API 密钥仅存于本机 Zotero 首选项，不写入导图或完整工作区备份；请保护 Zotero 配置文件。
- Zotero 附件同步与 AI 服务请求是两件事。导图归档为 `.mindflow` 附件后，跨设备可用性仍由 Zotero 文件同步设置与文献库权限决定。
