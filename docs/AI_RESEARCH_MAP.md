# AI 论文研究导图

面向 Zotero 10 中的**单篇常规文献**。MindFlow 把已下载且可提取的 PDF 文字、摘要、文献笔记和 PDF 批注整理为可编辑的研究导图，帮助读者快速找到研究问题、证据链与局限。导图是阅读辅助，任何科学判断都应回到原文核对。

## 从配置到归档

1. 打开 **编辑 → 设置 → MindFlow → AI 论文研究导图**，填写兼容 Chat Completions 的完整接口地址、模型名称和 API 密钥。本机模型可不填密钥。公网地址须使用 HTTPS；仅本机 `localhost`、`127.0.0.1` 和 `::1` 可使用 HTTP。
2. 可点击 **测试 AI 连接**。它只发送一句短文本，不发送论文内容；模型服务仍可能计费。测试成功仅表示接口按预期返回 `choices`，不保证该模型能稳定完成较长论文的结构化分析。
3. 在 Zotero 只选中一篇论文，右键点击 **AI 解析论文并生成研究导图**；MindFlow 工作台的 Zotero 菜单也有入口。
4. 工作台先在本机准备资料并展示来源清单、读取范围、未纳入的笔记或批注数量、目标模型和预计请求次数。此时**尚未向模型发送论文资料**。确认后选择快速概览或深入分析，点击 **开始分析**。
5. 运行中可查看当前阶段并取消。取消会中止正在进行的 HTTP 请求；已发出的请求仍可能由模型服务计费。出错后可重试，短时间内会复用本会话已准备的资料及已经完成的分段结果；关闭 Zotero 后不会保留这份会话缓存。
6. 生成结果先保存为**本机草稿**。在画布编辑、核对原文和删除不可靠的判断后，点击顶部提示条的 **归档到 Zotero**。归档成功后，导图作为所属文献的 `.mindflow` 子附件，后续编辑可继续同步。只读群组库或禁止写附件时，草稿保留在本机并显示失败原因。

草稿阶段按 `Ctrl/Cmd+S` 只保存本机。新导图不会覆盖原导图。同一文献可有多份导图，但阅读时应通过右键菜单或条目侧栏明确选择需要打开的那一份。

## 两种分析方式

| 模式 | 资料发送方式 | 适用情况 |
| --- | --- | --- |
| 快速概览 | 最多约 20,000 字符的 PDF 节选、精简摘要、最多 6 条笔记和 30 条批注一次发送 | 快速了解问题、体系和结论；费用与等待时间通常较低 |
| 深入分析 | 较长 PDF 分成最多约 24,000 字符的区间逐次分析，再结合摘要、笔记、批注整合 | 希望覆盖更多方法、结果与讨论；请求次数与费用可能显著增加 |

PDF 默认最多读取前 120 页，可在 Zotero 设置中选 50、120 或 200 页。读取文字超过约 144,000 字符时，MindFlow 会从不同位置采样并在导图中标明范围不完整。深入模式提升已提取内容的覆盖率，但不能替代未读取页面。扫描件、加密 PDF 或尚未下载的云端附件可能无法提供正文；插件不执行 OCR，也不会自动下载附件。

预览显示的是**准备的字符量与预计请求次数**，不是准确 token 或费用估算。模型分词、上下文长度和单价由所配置的服务决定。若模型报告上下文过长，可改用快速模式或降低 PDF 页数。

## 导图结构与证据边界

主干依次是研究背景、已有问题与知识缺口、研究目标、研究体系、方法设计、关键结果与证据、解决的问题、创新意义、局限和后续验证。资料不足的栏目保留“待阅读原文补充”。

模型收到的资料带有来源编号：`AB` 为摘要，`P1`、`P2` 等为本次发送的 PDF 文字片段，`N1` 等为 Zotero 笔记，`A1` 等为批注划线文字，`C1` 等为读者写下的批注评论。节点备注显示匹配后的来源编号和核对状态。**P 编号只是片段序号，不是页码。**

- **原文支持**：模型提供的短引文在本次发送的摘要、PDF 文字或 PDF 批注划线内容中找到文本匹配。匹配只能确认这段文字存在，不能证明模型对因果关系、创新性或科学意义的解释正确。
- **推断/待核验**：模型的解释、读者笔记支持的线索，或没有匹配到对应原文的判断。笔记和批注评论不会单独变成论文原文证据。
- **待解决**：开放问题与后续验证建议，不代表论文作者已经承认该局限，也不代表所建议的实验已实施。

MindFlow 先检查模型给出的编号是否属于本次输入，再在该编号的文字中查找短引文。模型没有填写编号时，只有引文在同类资料中**唯一匹配**才接受；重复文字、错误编号或不匹配的引文会降为待核验。深入模式的整合步骤还会检查 PDF 引文是否已经出现在分段草稿中。未通过核对的模型引文会保留在节点备注中，并明确标为“不能当作原文”，方便人工检查。根节点备注汇总原文匹配和需复核的条目数量。

批注节点若有 Zotero 定位链接，可返回原标注，并显示 Zotero 提供的页码标签。普通 PDF 文字节点只能打开关联 PDF：当前提取结果没有可靠的逐句页码定位，插件不会自动编造页码。根节点备注记录本次 PDF 状态、分析模式及资料范围。

## 数据、凭据与保存位置

- 点击 **开始分析** 后，题录、摘要、最多 12 条笔记、80 条批注和本机可读取的 PDF 文字会发往您配置的模型地址。资料在请求体中，MindFlow 不在 Zotero 调试日志中记录论文请求体，也不携带 Zotero 浏览会话 Cookie。
- API 密钥保存在本机 Zotero 首选项中，不写入导图或完整工作区备份。请选择可信任的模型服务，确认其隐私、授权、价格和数据保留规则。
- 分析前准备的资料仅在当前插件进程内暂存，最多保留少量条目并在短时间后失效。模型返回的导图草稿会持久保存在本机工作区，直到用户主动归档或删除。
- `.mindflow` 附件的跨设备可用性取决于 Zotero 文件同步设置、所属库权限和附件是否已下载；MindFlow 的 WebDAV 工作区备份是另一项功能。

## 遇到问题

| 症状 | 处理方式 |
| --- | --- |
| 提示未配置或连接测试失败 | 检查完整接口路径、模型名称、密钥和 HTTPS 证书；本机模型须已启动。 |
| 模型返回 429 或服务错误 | 检查服务商额度与状态，稍后重试；插件不会在后台无限重试以免重复计费。 |
| 模型未返回规定 JSON | 使用支持 Chat Completions 的模型，降低资料长度或换用更可靠的模型。 |
| PDF 正文缺失 | 在 Zotero 下载附件并确认可选中文字；扫描件需先由用户自行完成 OCR。 |
| 草稿无法归档 | 检查 Zotero 文献库和附件写入权限。草稿仍在本机工作区，可稍后重试。 |

请勿把模型生成的提要直接当作论文结论引用。原文短引文匹配是保守的文本核对，仍需要人工审阅上下文、方法和图表。
