## 2. 商店文案 (Copywriting)

### 简体中文 (zh_CN)

#### 简短说明 (不超过 132 字符)
> 极速、美观优雅的 Chrome 浏览器思维导图与伴读笔记，支持全屏沉浸创作、Side Panel 侧边伴读、大纲双向联动与 WebDAV 云同步。

#### 详细说明 (Detailed Description)
```markdown
🚀 MindFlow 是专为 Chrome 浏览器打造的现代化高颜值思维导图与知识伴读插件。
深度对标主流标杆（XMind、MindNode、ProcessOn），无需离开浏览器、无需注册账号，即可随心整理结构化知识。

✨ 为什么选择 MindFlow？
1. 【Chrome 伴读神技】完美支持 Chrome Side Panel 侧边栏模式，边浏览网页/论文/网课，边在右侧梳理大纲脑图。
2. 【网页一键入图】划词右键「📌 摘录到思维导图」，一键将当前网页标题与链接转为节点。
3. 【全键盘盲操】Tab 插入子分支、Enter 同级分支、Delete 删除、Space 内联编辑、方向键流畅穿梭。
4. 【10 大高颜值主题】经典商务蓝、极夜 OLED 深色、马卡龙糖果、护眼松柏绿、极简水墨、赛博朋克霓虹、学术纸感。
5. 【企业级数据安全】单文档多版本快照回滚、全量 JSON 备份迁移、存储配额监控，绝不丢失任何灵感。
6. 【WebDAV 云端漫游】原生对接坚果云、Nextcloud、群晖 NAS 等私网云盘，实现多台电脑跨端自动同步。
7. 【商业级演示模式】一键开启全屏 Presentation 演说模式，Space/方向键步进聚焦，汇报路演利器。
8. 【100% 离线隐私优先】所有数据均存于本地浏览器沙箱，零数据收集、零追踪探针。
```

## 3. 视觉宣传物料规范 (Store Assets)

| 素材类型 | 建议尺寸 | 格式 | 用途说明 |
| :--- | :--- | :--- | :--- |
| **小图标 (Icon)** | 128 x 128 px | PNG (透明通道) | 应用商店展示主图标 (`public/icons/icon128.png`) |
| **应用截屏 (Screenshots)** | 1280 x 800 px (或 640x400) | PNG / JPEG (无透明) | 最多 5 张，展示核心场景（大Tab画布、Side Panel、演示模式、WebDAV设置、多主题） |
| **小型宣传横幅 (Small Tile)** | 440 x 280 px | PNG / JPEG | 应用商店类别列表与搜索推荐图 |
| **大型宣传横幅 (Marquee)** | 1400 x 560 px | PNG / JPEG | Chrome Web Store 首页编辑精选轮播推荐位 |
