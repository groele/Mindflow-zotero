# MindFlow for Zotero v1.4.0

面向 **Zotero 10.0.x**。从本发布页 Assets 下载 **mindflow-zotero-1.4.0.xpi**，在 Zotero 的“工具 → 插件”窗口安装或升级。升级前建议导出完整工作区备份，并检查重要文献下已有的 `.mindflow` 附件已同步。

## 本版改进

- AI 论文研究导图增加资料范围预览。摘要、笔记、批注和 PDF 文字先在本机准备，用户点击“开始分析”后才发送到所配置的模型服务。
- 可选择快速概览或深入分析。长 PDF 跨区间采样；深入模式逐段分析已提取文字，再整合研究问题、体系、方法、证据和局限。
- 显示阶段进度并允许取消当前 HTTP 请求；增加连接测试和常见 HTTP 错误提示。模型请求禁用 Zotero 会话 Cookie 和请求体调试输出。
- 新导图先成为本机可编辑草稿，审阅后点击“归档到 Zotero”。草稿阶段 `Ctrl/Cmd+S` 仅保存本机。
- 可在 Zotero 设置中选择 PDF 文字读取页数上限：50、120 或 200 页，默认 120 页。批注引文可显示 Zotero 提供的页码标签；普通 PDF 文字不伪造页码。

## 使用限制

模型输出的短引文匹配只能确认文字存在，不能验证科学解释。PDF 文字超过约 144,000 字符时会跨区间采样；扫描件和未下载附件仍可能缺少全文。深入分析可能产生多次请求和费用。请在设置中确认模型服务的隐私与计费规则。

本版构建流程会执行 TypeScript 和宿主脚本语法检查并生成 XPI。若没有用户模型凭据或真实 Zotero 10 桌面操作记录，不应将构建成功表述为端到端验证通过。
