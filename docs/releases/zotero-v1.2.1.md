# MindFlow for Zotero v1.2.1

面向 **Zotero 10.0.x**。从本页 Assets 下载 **mindflow-zotero-1.2.1.xpi**，在 Zotero 的“工具 → 插件”窗口安装或升级。

## 本版内容

- 扩充 README，明确阅读器、文献列表和多份导图的打开规则。
- 补充升级、完整工作区备份、跨设备恢复及归档状态的操作说明和排障表。
- 同步 Zotero 插件版本与更新链接。本版没有导图功能或数据格式变更；Chrome 扩展继续使用独立的 3.2.0 版本号。

## 数据与验证

升级前建议导出完整工作区备份，并确认重要文献下的 `.mindflow` 附件已经同步。构建流程会检查 TypeScript 与宿主脚本语法并生成 XPI；尚未在 Zotero 10 图形界面完成安装和完整交互验证。
