# MindFlow for Zotero v1.6.7

适用于 **Zotero 10.0.x**。安装文件为 `mindflow-zotero-1.6.7.xpi`，可在 Zotero 的“工具 → 插件”窗口安装。升级前建议导出完整工作区备份，并确认重要文献下的 `.mindflow` 附件已经同步。

## 本版更新

- 优化欢迎页的文字层级、颜色对比、卡片间距及键盘聚焦；未选中唯一论文时显示明确引导。
- 在文献列表仅选中一篇文献时，新建的空白和模板导图直接归档为该文献的 `.mindflow` 子附件。
- 未选中文献时，新导图统一归档到个人库的 `MindFlow｜独立导图` 集合。集合中的 `MindFlow 独立导图` 常规条目容纳这些子附件。
- 多篇文献专题导图及分类导图也使用独立导图位置，避免误挂到第一篇参考文献。
- 保存成功后记录实际归档目标；再次编辑、打开附件或使用 `Ctrl/Cmd+S` 时继续更新同一目标位置。归档失败会保留本机导图并提示原因。
- 修复工作区启动与 Zotero 初始动作的时序问题，以及导入导图复用旧 Zotero 关联的问题。
