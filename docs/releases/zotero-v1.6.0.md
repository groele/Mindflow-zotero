# MindFlow for Zotero v1.6.0

适用于 **Zotero 10.0.x**。从本发布页 Assets 下载 **mindflow-zotero-1.6.0.xpi**，在 Zotero 的“工具 → 插件”窗口安装或升级。升级前建议导出完整工作区备份，并检查重要文献下的 `.mindflow` 附件是否已同步。

## 本版改进

- AI 分析前可分别选择是否发送摘要、PDF 文字、Zotero 笔记、批注划线和读者评论。预览显示使用的 PDF 附件、所选字符量，以及被截取、未纳入或读取失败的资料数量。
- 可取消资料准备。连续取消、重试或重新读取时，旧任务不会覆盖新任务的状态；长 PDF 的等待上限随预计模型请求次数调整。
- 深入模式对最终整合的分段候选与阅读材料做有界压缩，保留来源编号，并在导图中说明未进入最终整合的范围。引文只在实际发送的资料中核对。
- 单条 Zotero 笔记或批注读取失败时，其他资料继续处理并给出可见提示。

## 使用边界与验证

资料选择只控制**发送给模型的内容**；按“准备资料”后，MindFlow 仍会在本机读取可用的 Zotero 内容以便预览。快速模式和深入模式可能再次缩短已选内容。短引文匹配不等于科学结论已获证明。请查看 [AI 研究导图说明](../AI_RESEARCH_MAP.md)了解范围、费用和隐私边界。

已完成 TypeScript、宿主脚本语法和 XPI 构建检查。真实 Zotero 10 桌面端、用户模型服务、多 PDF 附件及跨窗口流程尚未完成实际验收；本版不应仅凭构建结果视为已达到正式上市验收标准。
