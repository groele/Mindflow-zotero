# MindFlow for Zotero v1.6.8

适用于 **Zotero 10.0.x**。本地安装包：`dist-zip/mindflow-zotero-1.6.8.xpi`。该版本尚未确认发布到 GitHub；请先使用本地安装包，并在 Zotero“工具 → 插件”中确认安装版本为 1.6.8。

## 修复内容

- 工作区在收到所选文献的创建请求前，先完成 Zotero 宿主握手与本机工作区加载。避免创建成功但未生成文献下的 `.mindflow` 子附件。
- Zotero API 检测先检查工作区自身已注入的对象，父窗口访问被隔离时仍可识别 Zotero 模式。
- 空白及模板导图从 Zotero 主窗口读取当前条目选择。单篇文献归档到该文献的子附件；确实未选中时归档到 MindFlow 独立导图位置；选择状态读取失败时显示错误并停止创建。
- 对已经留在独立导图位置的本机导图，可先打开该导图，再在文献列表中选中目标文献，返回工作区的 Zotero 菜单点击“存为文献条目附件 (.mindflow)”重新归档。原独立附件不会自动删除，请确认新附件存在后自行整理旧副本。
