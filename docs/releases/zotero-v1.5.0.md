# MindFlow for Zotero v1.5.0

适用于 **Zotero 10.0.x**。从本发布页 Assets 下载 **mindflow-zotero-1.5.0.xpi**，在 Zotero 的“工具 → 插件”窗口安装或升级。升级前建议导出完整工作区备份，并检查重要文献下的 `.mindflow` 附件是否已同步。

## 本版改进

- AI 生成时给摘要、PDF 片段、文献笔记、批注划线和读者评论分配独立来源编号。节点备注显示匹配的来源、编号和核对状态。
- 模型的短引文必须出现在指定编号的资料中；未填写编号时，只接受能唯一定位到某一资料片段的引文。重复、错误编号和不匹配的引文保留为需人工核查的模型输出。
- 深入模式的整合阶段只能引用前面分段分析提出的 PDF 引文；整合时新增或改写的引文不会获得“原文支持”标记。
- 批注划线文字与读者评论分开处理。评论和笔记可以提供阅读线索，但不会被标为论文原文证据。
- 导图根节点汇总有原文片段匹配与需要复核的条目数。PDF 的 P 编号表示本次分析的文字片段，不表示页码。

## 使用边界

文字匹配只能确认引文存在于本次输入，不能验证模型对论文方法、因果关系或创新性的解释。长 PDF 仍受读取页数和字符采样范围限制。调用外部模型可能产生费用；具体使用请参阅 [AI 研究导图说明](../AI_RESEARCH_MAP.md)。

本版已完成 TypeScript、宿主脚本语法和 XPI 构建检查；尚无真实 Zotero 10 桌面端与用户模型服务的完整运行验证。
