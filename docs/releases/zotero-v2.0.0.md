# MindFlow for Zotero 10 v2.0.0 (Major Release)

MindFlow v2.0.0 是里程碑式的重大架构与体验升级版本，重点解决文献附属笔记摘要重复冗余、文献子附件保存与多文献多标签页隔离防串台问题。

---

### 🌟 核心更新亮点

#### 1. 💡 附属文献笔记（Note）摘要去重与结构纯化
- **消除双重摘要**：彻底消除此前在附属创建的导图大纲笔记（Note）中同时在根标题下与核心摘要分支中出现两次摘要的冗余问题。
- **独立结构化归拢**：根节点仅保留文献标题与链接，全文摘要统一归入 `💡 核心摘要` 专属分支。
- **大纲渲染优化**：智能过滤核心摘要下重复的截断子节点，大纲输出排版紧凑清晰，呈现高质量学术导图笔记。

#### 2. 🛡️ 文献子附件存储安全架构升级
- **PDF 同级子附件归档**：彻底修复导图文件未正确保存在当前条目下的缺陷。导图现在严格作为文献的直接子附件（`.mindflow` 文件）进行多副本安全归档，并与 PDF 平级。
- **原子落盘与灾备自检**：工作区导图写入 Zotero 数据目录 `mindflow/workspace`，采用临时文件原子替换、写入后即时回读校验与 `.bak` 副本机制，保障学术数据永不丢失。
- **真实保存状态报告**：杜绝内存伪保存提示，清晰报告“本地备份”与“Zotero 文献子附件”的双重归档结果。

#### 3. 📑 多标签页深度隔离与防串台
- **精准条目上下文追踪**：基于 Zotero 文献 URI 与阅读器（Reader）标签页精准识别当前操作目标，在不同文献条目打开导图时严格隔离，彻底解决跨文献串台和错误打开同一导图的问题。
- **智能工作台激活**：对同一文献优先聚焦已有标签页或独立窗口，对新文献自动加载对应文献专属导图。

#### 4. 🎨 导图卡片排版与视觉优化
- **长标题优先展示**：根节点卡片宽度扩展至 520px，移除挤占标题空间的标签胶囊，保障学术论文长标题完整、美观展现。
- **结构化分支去噪**：移除冗余的 `🏷️ 标签` 树形分支，专注呈现出版信息、核心摘要、阅读批注与关联笔记。

---

### 📦 安装与升级指南
1. 从 GitHub Release 下载 `mindflow-zotero-2.0.0.xpi`。
2. 打开 Zotero 10，进入 `工具 -> 附加组件 (Tools -> Add-ons)`。
3. 点击右上角齿轮图标，选择 `从文件安装附加组件 (Install Add-on From File...)`。
4. 选择 `mindflow-zotero-2.0.0.xpi` 并确认安装，重启 Zotero 即可体验全新 v2.0.0。
