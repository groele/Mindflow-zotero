# MindFlow for Zotero v1.6.5

适用于 **Zotero 10.0.x**。从本发布页 Assets 下载 **mindflow-zotero-1.6.5.xpi**，在 Zotero 的“工具 → 插件”窗口安装或升级。升级前建议导出完整工作区备份，并检查重要文献下的 `.mindflow` 附件是否已同步。

## 本版更新

- 统一扩展、工作台与 Zotero 的思维导图品牌符号，提供清晰的 16、48、128 像素图标。
- Zotero 工具栏采用透明底的灰色节点线稿，并排在原生工具按钮之后。
- 收敛工作台工具栏与侧栏图标配色，任务优先级标记改为中性色。
- 重做 MindFlow 设置面板的排版，使分组、标签和控件更贴合 Zotero 原生偏好页。
