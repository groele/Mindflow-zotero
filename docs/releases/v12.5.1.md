# Zotero MindFlow 12.5.1

Released: 2026-10-21

- Publish the installable XPI for the unified Zotero Flow branding and settings presentation.
- Align the manifest, settings version label, package metadata, current README download links, and automatic update feed with 12.5.1.
- Use the shared `v12.5.1` GitHub tag format and attach `zotero-mindflow-12.5.1.xpi` to the Release.

Install `zotero-mindflow-12.5.1.xpi` through Zotero's add-on manager. Do not install the GitHub source archive.

The release build and archive integrity checks are recorded in the accompanying `package-verification.json`. Desktop Zotero installation and external service workflows have not been revalidated for this packaging release.

## Verification limits

The production build, TypeScript, JavaScript syntax and XPI resource checks passed. The host regression suite passed 68 of 81 tests. The same 13 failures were reproduced against the unmodified source at the source base commit. They concern reading-scope and item-pane behavior; this packaging release does not resolve them. This release is not a full functional acceptance result.
