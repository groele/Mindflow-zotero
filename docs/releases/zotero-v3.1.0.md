# MindFlow for Zotero 10 v3.1.0 (全面稳定性与系统优化)

MindFlow **v3.1.0** 是针对核心稳定性、多场景并发体验与学术伴读联动的全面升级版本。重点修复了新建空白导图时的异步并发竞态、PDF 附件跨版本兼容、右键菜单动态视口边界、设置面板原生 AI 模型配置以及外部文件导入历史栈等一系列关键问题。

---

## 🌟 V3.1.0 核心更新亮点

### 1. 🛡️ 新建空白导图与文献导图加载并发竞态彻底修复 (Race Condition Guard)
- **动态令牌作废机制**：引入 `activeDocLoadTokenRef` 令牌体系。当用户点击“新建空白导图”或切换不同导图时，即刻作废正在异步并发读取的 Zotero 选中条目文献数据，彻底根除“新建空白导图后被迟到的文献导图异步覆盖”的问题。
- **状态与缓存清理**：新建空白导图时主动清理挂起的首选项工作区引导加载器及 `_mindflowInitialAction` 缓存，并阻止对未命名空白导图进行非预期的 Zotero 条目自动归档。
- **工作区重载状态同步**：重构 `reloadWorkspace` 方法，全面同步内部多级 ref（`latestDocRef`、`cleanDocRef`、`currentDocIdRef`、`latestRelationshipsRef`），杜绝因引用陈旧导致的撤销/保存状态错乱。

### 2. 📖 PDF 阅读器与文献穿梭联动健壮化
- **兼容 Zotero 7/8+ 异步附件接口**：彻底重构 `openItemPdfInZotero`。全面兼容 `item.getBestAttachment()` 返回 `Promise` 与同步对象的两种情况，并在底层阅读器就绪后精准激活对应 PDF 标签页并触发划线批注跳转。

### 3. ⚙️ 设置面板新增专属原生 AI 模型与网络端点配置中心
- **独立 AI 配置面板**：在设置面板新增直观的“AI 模型配置”专属标签页，支持直接配置 API 地址、模型名称、API Key 与最大解析页数。
- **即时连通性诊断与双向同步**：内置一键连通性测试诊断器，实时显示网络耗时与响应状态；自动双向同步 `extensions.mindflow.ai.*` 与内部应用配置。

### 4. 🖱️ 全域右键菜单动态测量与边界防溢出
- **视口自适应钳位**：`ContextMenu` 引入 `useLayoutEffect` 精准测量 DOM 实际渲染高度与宽度，根据视口安全边界智能调整向上/向左弹出。
- **防溢出滚动保护**：为长菜单添加 `max-h-[calc(100vh-2rem)] overflow-y-auto` 滚动保护，杜绝超长菜单在屏幕底部被截断无法点击的问题。

### 5. ⚡ 节点批量删除与文件导入历史栈修复
- **批量删除焦点平滑过渡**：修复批量选中多个节点并执行删除时，焦点节点错位与多选状态残留问题。
- **导入撤销/重做栈重置**：从 JSON、Markdown、OPML 导入新导图时，自动重置历史撤销栈并同步历史快照状态，防止撤销导致导图破损。

### 6. 💡 欢迎向导库选区动态轮询与保存提示防抖
- **活动条目动态侦测**：欢迎向导对话框引入 1.5s 周期性轮询与手动刷新按钮，保证在后台切换文献时向导提示同步更新。
- **保存指示器防抖平滑化**：将保存指示器的切换置入防抖计时器内，消除高频编辑过程中的保存状态瞬时闪烁。

## 📦 安装与升级指南

1. 从 GitHub Release 下载 `mindflow-zotero-3.1.0.xpi`；
2. 打开 Zotero 10 客户端，点击菜单栏 `工具 (Tools)` → `附加组件 (Add-ons)`；
3. 点击右上角齿轮图标 ⚙️，选择 `Install Add-on From File...`；
4. 选中已下载的 `mindflow-zotero-3.1.0.xpi` 并确认安装；
5. 重启 Zotero 即可开启全新 V3.1.0 科研导图之旅！
