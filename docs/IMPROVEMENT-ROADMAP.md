# MindFlow 产品、稳定性与数据安全审查

## 审查范围

审查了当前 2.5.0 源码中的思维导图数据模型、画布和节点编辑、历史记录、存储、快照、备份导入导出、WebDAV 与扩展权限。对照了 Xmind、MindNode、MindMeister 的公开产品资料，以及 Chrome 扩展存储和权限文档。

本次是源码和产品资料审查。当前环境的内嵌浏览器自动化连接未能建立，因此没有把产品运行画面或真实 Chrome 扩展交互作为证据；画布性能、键盘/读屏体验、Chrome 运行权限、跨窗口行为和 WebDAV 服务端兼容性仍需真实运行核验。

## 已完成的改进

1. **保存失败现在可见。** 主导图写入会检查 Chrome Storage 错误；工具栏显示保存状态，自动备份失败会区分“本地已保存”和“云端失败”。
2. **主导图和索引合并写入。** Chrome Storage 使用一次批量写操作保存文档和目录索引；索引损坏时尝试从现存文档重建，避免空白索引把已有导图隐藏。
3. **自动版本快照设置开始生效。** 编辑后按所设间隔生成快照，并按设置的数量上限保留；此前这两个设置值只有界面，没有接到保存流程。
4. **导入先验证，再修改数据。** 工作区备份和单图 JSON 在首次写入前检查导图、节点 ID、层级、节点数量、关系线端点、收集箱和快照关联；JSON 导入限制为 20 MB。恢复将覆盖同 ID 的本地导图前先保存一个恢复快照。
5. **扩展权限按需申请。** 移除了安装时对所有 HTTP/HTTPS 网站的必需访问权。用户实际测试或使用 WebDAV 时，只请求配置服务器的 HTTPS 域名权限。HTTP WebDAV 被拒绝，以免 Basic Auth 密码明文传输；路径也不能将请求切换到其他域名。
6. **减少扩展存储的暴露面。** 后台把本地存储限制到扩展可信上下文，并更正备份说明：备份包含导图、收集箱和快照，不包含 WebDAV 密码或设置。
7. **导出反馈和下载时序更稳妥。** 备份生成失败会显示原因，对下载对象 URL 延后释放，避免浏览器尚未读取时就撤销。
8. **收紧 SVG 和交互式 HTML 的颜色字段。** 导入内容中的节点颜色不再未经限制地写入导出标记/样式，降低恶意备份影响导出文件的风险。
9. **为本地导图保存增加版本检查。** 扩展界面的写入交给后台顺序处理；旧版本写入会被拒绝，编辑内容自动保存在新的“冲突副本”中。后台右键菜单也通过同一存储服务写入。
10. **WebDAV 保留独立历史文件。** 每次上传先写入带 UTC 时间和随机后缀的 JSON，再更新兼容旧版本的“最新备份”文件。设置中可列出并选择历史版本恢复；自动云备份在停止编辑 15 秒后触发，同一页面中的上传按顺序执行，云端网络不会阻塞后续本地保存。
11. **增加当前导图任务总览。** 工作台提供完成比例、进行中和逾期数量，以及状态、逾期和文本筛选；点击任务可定位画布节点。

## 仍值得优先处理

### P1：保护并发编辑和远端备份

- **继续完善多窗口冲突体验。** 目前能拒绝旧版本覆盖并另存副本；下一步需要冲突差异预览、合并选择，以及删除文档与保存文档的统一串行事务。
- **完善 WebDAV 历史管理。** 现在已保留可选择恢复的历史文件，但还没有自动保留数量限制、失败重试和跨窗口统一上传队列；多个页面同时上传时，“最新备份”可能不是时间最新的版本，历史文件仍可恢复。
- **完善云端状态。** 自动备份已延迟合并并在本地保存之后进行；下一步可展示明确的等待/上传状态、最近成功时间和云端空间占用。
- **导入/导出作为完整事务。** 当前导入会在验证后保存文档、收集箱和多个快照，但跨这些记录仍不是一个原子事务。若空间在中途耗尽，部分数据可能已写入。后续可先估算空间、构造完整写入集合，再一次提交；失败时保留恢复点并报告未完成部分。
- **限制大图的卡顿。** 编辑会触发整棵树布局计算；历史记录每步序列化并深拷贝树。大图建议先做真实基准，再加可见区域虚拟化、增量布局和结构共享历史，避免未经测量就替换渲染架构。

### P2：补齐高价值思维导图工作流

- **扩展任务视图。** 当前导图已支持任务筛选与完成比例；跨导图任务收件箱、负责人字段和父任务分支进度汇总仍待设计。
- **标签和标记聚焦。** 节点已有 tags/icons 字段；把标签作为可筛选、可高亮的视图，并提供优先级、进度、风险等可命名标记与图例。MindNode 的标签聚焦、Xmind 的标记图例是成熟参考。
- **总结、边界和分组区域。** 对树结构以外的分组加入明确的数据模型，支持给一组主题加边界/摘要，而不是用普通节点模拟。Xmind 将 relationship、summary、boundary 和 marker 分作独立结构。
- **跨图链接。** 现有关系线适用于单图节点；增加稳定的文档/节点目标 ID，让节点能跳转到另一张图的指定主题，并在目标删除时给出可修复链接。
- **结构视图。** 现有思维导图、逻辑图、组织图可继续扩展为时间线、鱼骨图、矩阵和自由分组视图。应保持共享节点数据，让结构切换不会复制或破坏内容。
- **更可靠的快速捕获和演示。** 将浏览器收集箱、节点备注、快捷输入和演示大纲整合成明确流程；支持从节点生成可排序的演示页，并让演示视图不改变原始层级。
- **更多内容类型需先解决附件存储。** 模型声明了 image 类型，但产品级图片/附件仍需校验、体积限制、备份策略和导出语义；音频、公式和文件附件适合等附件存储与迁移设计完成后再加入。

### P2：安全、隐私和可恢复性

- **WebDAV 凭据目前仍保存在扩展本地设置中。** Chrome 文档明确说明扩展存储不提供应用层加密。本次限制了扩展上下文并拒绝明文 HTTP，但这不是静态加密。要降低设备被他人访问时的风险，可改为启动时重新输入凭据，或设计有清晰威胁模型的加密/系统密钥库方案；不要把加密密钥与密文一起放在同一个本地存储中。
- **本地浏览器扩展存储仍有限。** Chrome Storage Local 当前默认上限为 10 MB；不要仅为消除配额提示就盲目增加 `unlimitedStorage`。当图片和附件进入产品后，应迁移二进制内容至 IndexedDB/文件系统，并为用户提供配额、导出和迁移工具。
- **差异化备份与恢复预演。** 导入前显示将新增、覆盖、合并的导图数量与标题，允许预览冲突，并保留撤销/恢复入口。当前只按 ID 合并，用户可能不知道哪些内容会被替换。
- **隐私数据生命周期。** 补充“清除所有本地数据”、WebDAV 凭据清除、历史快照清理和备份文件提醒；卸载扩展前提示先导出，因为 Chrome 扩展本地数据会随卸载移除。
- **后台收集失败反馈。** 右键菜单现已走版本化存储服务，但冲突时只写入控制台日志；仍需向用户显示可重试的失败状态。

## 商业产品参考与可迁移模式

- [Xmind 功能页](https://xmind.com/features/)：关系线、摘要、边界、标记图例、备注、更多结构和格式互通。适合借鉴“每种语义对象有独立的数据结构和编辑操作”。
- [MindNode 功能页](https://www.mindnode.com/features)：大纲和画布联动、标签高亮、焦点模式、任务、跨文档链接与广泛导出。适合借鉴“一个内容模型，多种工作视图”和“先捕获、再整理、最后执行”。
- [MindMeister 更新页](https://mindmeister.com/pages/updates)：版本历史、评论/提及、实时协作光标和演示模式。协作功能需要服务端同步和冲突模型，不能只在当前本地扩展里加 UI。
- [Chrome Storage API](https://developer.chrome.com/docs/extensions/reference/api/storage)：本地存储默认可暴露给内容脚本，可用 `setAccessLevel` 缩小范围；local 默认 10 MB，写入可因超额拒绝；`storage.sync` 约 100 KB 总量/8 KB 单项，不适合导图正文。
- [Chrome 可选权限建议](https://developer.chrome.com/docs/extensions/develop/concepts/declare-permissions) 与 [Permissions API](https://developer.chrome.com/docs/extensions/reference/api/permissions)：对 WebDAV 这类可选功能，应在用户启用时解释并申请所需的最小域名范围。
- [Chrome 用户隐私建议](https://developer.chrome.com/docs/extensions/develop/security-privacy/user-privacy)：减少不必要权限，不应把扩展本地存储误当成加密保险库。

## 推荐实施顺序

1. 完成当前补丁的真实 Chrome 加载、保存失败、配额满、损坏备份、同 ID 恢复、WebDAV 无权限/拒绝权限/HTTPS 上传和多窗口并发核验。
2. 在真实 Chrome 中核验多窗口编辑、冲突副本、WebDAV 历史列出与恢复，然后完善冲突差异预览和跨窗口云端上传调度。
3. 增加标签高亮、跨导图任务收件箱与分支进度，沿用当前节点模型。
4. 设计 boundary/summary 和跨文档链接的持久化格式，再做时间线/鱼骨/矩阵结构视图。
5. 图片和附件存储、跨设备同步、加密凭据、实时协作属于更大版本，先确认目标用户与同步/隐私边界。
