# 工具栏图标尺寸修复 — 10.0.1

用户截图中的 MindFlow 拓扑图标明显小于同一工具栏的原生图标。原实现将图像限制为 16×16，原 SVG 又在 32×32 视口中保留较多外围空白，两者共同缩小了可见图形。

工具栏图像现为 20×20，配合专用 `mindflow-toolbar.svg` 的紧凑视口，让可见图形与邻近原生图标接近。菜单、标签与工作台继续使用原 SVG。图标旁保持无文字，保留工具提示和可访问名称。

真实 Zotero 10.0.3 在显示文献库工具栏时，MindFlow 图像和原生“新建笔记”图像均测得 20×20 CSS 像素。测量见 `toolbar-icon-metrics-10.0.1.json`，截图见 `toolbar-icon-preview-10.0.1.png`。

本地安装包为根目录 `mindflow-zotero-10.0.1.xpi`，类型检查、生产构建和语法检查通过。原生回归检查增加了与真实原生图标尺寸的比较；当前结果见 `toolbar-icon-validation-10.0.1.json`，安装包校验见 `toolbar-icon-package-10.0.1.json`。

公开 V10 的安装包与更新通道仍为 10.0.0。本地补丁使用相同插件 ID，可以覆盖安装；在 Zotero“工具 → 插件 → 从文件安装插件”选择 10.0.1 XPI，安装后重启。
