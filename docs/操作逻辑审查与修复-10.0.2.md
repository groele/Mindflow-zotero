# MindFlow Zotero 操作逻辑详细审查与修复（10.0.2）

日期：2026-09-28。审查基线为本目录的 10.0.1，修复版本为本地 10.0.2。

本轮整理并处理了 **29 项操作逻辑问题与加固点**，涵盖编辑、关系线、撤销、多选、大纲、收集箱、设置、导入、备份和 AI 请求控制。它们不与历史文档中的 42 项、28 项重复累计。表中的“基线复现”表示原代码确实执行失败；“代码确认”表示通过实际调用链确认缺陷，不能据此宣称已经观察到用户数据丢失。

## 1. 原始问题和复现证据

- 原有宿主 **36/36**、前端 **24/24** 测试均通过；因此这些测试不足以证明全部编辑流程正常。
- 第一批 9 个新增前端复现检查中，原实现 **8 个失败**：任务克隆共享、大小写替换不一致、收集箱并发丢失、收集箱无效数据未拒绝、并发设置覆盖、无效 OPML 被接受、备份重复收集箱 ID 等。随后扩展为最终 17 个逻辑测试。
- 扩展宿主检查在保留的 10.0.1 宿主源码上 **36/42 通过**。其中两个 AI 测试直接复现超时失效与取消误报；另四项表明旧宿主尚无新的收集箱原子操作，不能把这四项计成四个独立旧缺陷。日志见 [基线宿主结果](logic-audit-baseline-host-10.0.1.txt)。
- 将未修改的 `mindflow-zotero-10.0.1.xpi` 安装到隔离 Zotero 10.0.3 后，扩展界面脚本 **26/33 通过**。直接失败包括删除连接分支不能落盘、重做留下无效连线、关系线撤销改变了无关节点、中文组合输入提前提交；两个后续检查受前置失败影响，没有单独计作独立复现。见 [原生基线](logic-audit-baseline-native-10.0.1.json)。
- 首次修复后的真实测试还发现“大纲切到文档库时输入框先被卸载”的遗漏。修复前结果单独保留为 [中间原生结果](logic-audit-intermediate-native-10.0.2.json)。最终修复覆盖侧栏、工具栏、命令面板和禅模式入口。

## 4. 交付与复查方式

- 安装包：[mindflow-zotero-10.0.2.xpi](../mindflow-zotero-10.0.2.xpi)。这是本地修复版本，本轮没有发布 GitHub Release 或变更公开自动更新源。
- 原源码、宿主脚本和前端包在 `backups/logic-audit-10.0.1-20260928-214748`；原 10.0.1 安装包保留。没有替换用户日常使用的 Zotero 文献库或配置。
- 执行 `npm --prefix source test` 跑完全部 42 个前端检查；执行 `node --test scripts/test-host.mjs` 跑宿主检查。`node scripts/build-local.mjs` 构建，`python scripts/package-xpi.py` 打包并逐文件核对。
- `scripts/start-native-test.ps1` 创建新的隔离数据目录；原生脚本完成并退出后用 `scripts/restart-native-test.ps1` 验证实际重启。
