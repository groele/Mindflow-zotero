## 修复与加固范围

10.0.3 汇集了操作逻辑审查处理的 **29 项编辑、数据与交互加固** 以及 **工具栏图标尺寸与显示优化**：

1. **操作逻辑与数据一致性（R01 - R29）**：
   - **树编辑与关系线保护**：删除含连线分支时自动清理失效连线端点（R01）；历史栈统一纳入节点树与关系线（R02）；撤销/重做同步校正选中与编辑 ID（R03）；深拷贝任务独立性（R04）。
   - **输入与草稿捕获**：大纲切换侧栏、收起工作台或进出禅模式前可靠捕获未提交文字草稿（R05）；组件按文档 ID 隔离防串扰（R06）；弹窗快捷键隔离与阻断（R07）；多选清空校正主选中（R08）。
   - **搜索与替换增强**：大小写不敏感统一匹配（R09）；准确按实际文字替换计数（R10）；搜索与内链定位自动展开折叠祖先（R11）。
   - **收集箱并发与防重复**：Zotero 宿主串行队列原子 `mutateInbox`，消除并发读改写丢失（R12）；收集箱入图完成后再标记已处理（R13）；操作防重复点击守卫（R14）；数据结构与重复 ID 前置校验（R15）。
   - **设置与 WebDAV 同步**：设置并发合并（R16）；WebDAV 单字段局部补丁合并（R17）；设置深拷贝隔离（R18）；WebDAV 自动备份配置校验与失效任务拦截（R29）。
   - **输入法与导入导出**：大纲回车输入法合成状态保护（R19）；OPML XML 严格解析与校验（R20）；导入错误统一捕获与反馈（R21）；导图克隆仅重映射自链接（R22）；移除虚构配额（R23）；图片加载任务序号保护（R24）。
   - **AI 请求可靠性**：请求超时计时器与主动取消 AbortSignal 联动解耦，超时准确返回 408，主动取消保留 AbortError（R28）。

2. **工具栏与侧栏界面优化**：
   - 专用紧凑 SVG 视口 `mindflow-toolbar.svg`，尺寸精准适配为 20×20 CSS 像素，与 Zotero 原生“新建笔记”图标视觉平衡一致。
   - Item-pane 侧边栏窄条按钮使用 tooltip-only 本地化，防止文字横向溢出换行。
