# 🏛️ MindFlow 架构决策记录 (DECISIONS.md)

## ADR-001: 采用 HTML Node + SVG Edge 混合渲染模式
- **背景**：思维导图图形引擎通常有三种方案：全 Canvas、全 SVG、HTML+SVG 混合。
- **决策**：选用 HTML 节点 + SVG 连接曲线。
- **收益**：
  1. 保证了在任何屏幕分辨率下中英文输入、IME 组合事件无任何闪烁与错位；
  2. 简化了节点上交互控件（如复选框、超链接、折叠徽标）的 DOM 事件绑定；
  3. SVG 曲线利用浏览器硬件加速绘制，缩放无锯齿。

## ADR-002: 采用本地优先（Offline-First）存储体系
- **背景**：浏览器插件常面临跨域、账号鉴权、网络中断等问题。
- **决策**：优先采用 `chrome.storage.local`，并优雅降级至 `localStorage`。
- **收益**：保护用户数据隐私，无需服务器成本，离线完全可用。

## ADR-003: 引入独立 Inbox 收集箱作为浏览器工作流枢纽
- **背景**：网页浏览具有碎片化特征，直接打乱正在创作的导图会打断心流。
- **决策**：设立独立的 Inbox 缓冲池。
- **收益**：划词和剪藏先存入收集箱，用户在深度思考时再批量拉入导图，极大提升了使用频率与整洁度。

## ADR-004: 人机工程学模块分区（左侧宏观工作台 vs. 右侧微观检视器 + 停靠对调）
- **背景**：思维导图软件功能繁多，若将所有工具混杂在一侧，会导致视觉噪音大、操作拥挤；若置于错误侧边，会违背用户认知动线。
- **决策**：
  1. **左侧（宏观导航与内容管理）**：文档目录（Docs）、树状大纲（Outline）、灵感收集箱（Inbox）、数据安全与快照（Backup）。符合自左向右阅读的认知习惯，方便快速扫视和全局把控。
  2. **右侧（微观节点检视与样式配置）**：节点属性面板（PropertySidebar），包含节点外观（形状、边框、填充）、任务流转（状态、优先级、截止日期）、标签、链接与富文本备注。仅在选中节点时按需提供聚焦式配置。
  3. **对称互换停靠（Swappable Docking）**：提供一键左右对调布局机制，针对 Chrome Side Panel（用户常停靠在右侧或左侧不同屏幕习惯）完美自适应。

## ADR-005: 多层次数据安全与备份架构（Version Snapshots + Full Workspace Export）
- **背景**：浏览器插件纯本地存储存在浏览器清理缓存导致数据误删、或者用户编辑错误需要回滚历史的风险。
- **决策**：构建三层数据防御：
  1. **单文档滚动版本快照（DocSnapshots）**：每个导图自动/手动维护多达 20 个完整历史快照，支持精准一键还原。
  2. **工作区全量一键打包（Workspace Backup）**：将所有导图、收集箱条目、快照整合导出为标准化 `.json` 文件，支持跨电脑/跨浏览器无缝迁移还原。
  3. **实时存储配额监控（Storage Quota）**：精准计算 `chrome.storage.local` 占用与剩余字节，防止超出上限引发写入失败。

## ADR-006: 基于 WebDAV 的去中心化点对点云同步方案
- **背景**：云端协作思维导图往往依赖中心化服务商（涉及账号体系、数据泄漏隐患、服务停止运营风险）。
- **决策**：选用通用开放协议 WebDAV（兼容坚果云、Nextcloud、ownCloud、群晖 Synology 等）。
- **收益**：
  1. 真正实现零服务器中转的端到端同步，扩展直接在浏览器底层与目标 WebDAV 端点通信；
  2. 用户拥有 100% 数据资产掌控权，授权密码仅存放于本地 Extension Storage。

## ADR-007: 声明式配置驱动的工具栏与界面自由定制
- **背景**：不同用户屏幕尺寸（笔记本、超宽屏、分屏伴读、Side Panel）差异巨大，固定工具栏和固定按钮在小屏拥挤不堪，在大屏利用率不足。
- **决策**：构建 `AppSettings` 驱动的声明式渲染层，将工具栏位置（顶部 vs. 底部）、工作台停靠（左端 vs. 右端）、10 项按钮显隐以及画布纹理全部抽离为配置项。
- **收益**：实现千人千面的极度个性化工作台，同时保持代码高内聚与零冗余。
